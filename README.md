## About The Project

The **Banking Loan Applications Analysis** project is created using **Microsoft Power BI** to analyze banking loan application data.

The project focuses on transforming raw data into meaningful business insights through **data cleaning, data transformation, DAX calculations, KPIs, and interactive visualizations**.

The dashboard helps users easily understand loan application patterns and explore different aspects of the data.
